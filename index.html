📖 Quick Reference Guide

💾 Data Backup & Sync

⚠️ Important: Your data does NOT sync automatically between devices!

MacBook Chrome and iPhone Chrome have separate data. To sync:

  • Create Checkpoint on one device
  • Save the .dent file to iCloud Drive
  • Restore Checkpoint on other device
  • Both devices now have same data!
💡 Pro Tip: Create checkpoints every Sunday! Set a phone reminder.

🔄 Future Updates

When you need new features:

  • Before using new version: Create checkpoint
  • Get the updated app from Claude
  • Restore your checkpoint - data migrates automatically!
  • All your data works perfectly ✅

💊 Medication Tracker

Click the status message to expand calendar view!

  • 🟢 Green = Have pill for this day
  • 🔴 Red = No pill (weekday - critical!)
  • 🟡 Yellow = No pill (weekend)
  • 🔵 Blue = Extra pill (surplus)
  • 🟣 Purple = Refill day

Buttons:

  • "✓ Took Daily Dose" = Take both pills at once
  • "+ Add Pill" / "- Remove Pill" = Manual adjustments
  • "⚙️" = Settings (set pill count & refill date)

✅ Tasks & XP

  • Each task = 20 XP
  • Track 7 categories of tasks
  • Check off tasks to earn XP
  • Use Pomodoro timer for focus sessions
🔴 Do Today Feature: Mark critical tasks with "Do Today" button. They'll appear in both their original category AND the "Critical Must Do Today" category. When completed, they disappear from "Do Today" but stay in original category. XP only counted once!

🆘 Emergency Recovery

If data disappears:

  • Click 📂 Restore Checkpoint
  • Select your most recent .dent file
  • All data restored instantly!
Prevention: Keep 3-4 recent checkpoints in iCloud Drive

📱 Recommended Setup

  • Primary device: MacBook (easier to type)
  • Backup location: iCloud Drive folder
  • Checkpoint schedule: Every Sunday
  • Before updates: Always create checkpoint first

🎯 Quick Commands

Keyboard shortcuts: None needed - just click!

Best workflow:

  • Morning: Check medication calendar
  • Add tasks as they come up
  • Use Pomodoro timer when studying
  • Check off tasks when done
  • Sunday: Create weekly checkpoint
