## Global rules (every task)

- Surgical `Edit` only. Read the target section first. Never rebuild a whole file.
- `getValues()` for all Firebase collection reads. `?? null` / `?? false` for anything saved (no `undefined`).
- CRUD: `safeLocalStorageSet(STORAGE_KEY, JSON.stringify(roadmapData))` BEFORE `saveData()`. Clinical CRUD also sets `clinicalDataDirty = true` first.
- No `saveData()` / state mutation in render paths.
- `escapeHtml()` on all user text in innerHTML; `onclick` string IDs quoted `'${id}'` with `'"\\` stripped.
- Dates: `getLocalDateString()` / `parseLocalDate()`; never `new Date('YYYY-MM-DD')` or `.toISOString().slice(0,10)`.
- After each task: `node --check` on every touched JS file, then commit.
